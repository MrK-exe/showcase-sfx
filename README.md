# showcase-sfx

Menu sounds for [mrk-exe.github.io/showcase](https://mrk-exe.github.io/showcase/).

`ds-a/` holds five short menu sounds from Death Stranding by Kojima Productions: `hover`, `nav`, `click`, `open` and `close`. They are trimmed clips used only as interface sounds on a personal, non-commercial portfolio, and the site credits the game in its footer.

This repo isn't affiliated with or endorsed by Kojima Productions or Sony Interactive Entertainment. If you hold the rights and want these removed, open an issue or email abdullahk.aletai@gmail.com and they'll be taken down.

The sounds live here, apart from the site's own repo, on purpose: if this repo goes away, the site keeps working and falls back to its own synthesized sounds.
